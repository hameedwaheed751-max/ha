# أجهزة المتجر داخل «المشتريات» (Store Device Listings)

Design spec — 2026-11-12 (امتداد لـ `2026-11-12-agent-stores-purchases-design.md`)

## 1. الهدف

يرفع الوكيل **أجهزته للبيع** داخل متجره في «المشتريات»: لكل جهاز **صورة
(أو عدة صور) ووصف**، مع اسم وسعر ورقم واتساب للطلب. يتصفّح بقية الوكلاء
المتاجر، وعند فتح متجر تظهر أجهزته، وبالضغط على جهاز تظهر تفاصيله.

## 2. القرارات المعتمدة (من المستخدم)

- **البنية:** متجر لكل وكيل + أجهزته بداخله. يصبح **رابط الموقع اختيارياً**
  (المتجر حاوية أجهزة، لا مجرد رابط).
- **حقول الجهاز:** صورة(ات) + وصف (أساسيان) + اسم/عنوان + سعر + واتساب +
  **عدة صور**.
- **الاعتماد:** يُعتمد الوكيل/المتجر **مرة واحدة** (كما الآن)، ثم يضيف
  أجهزته ويعدّلها/يحذفها **بحرية بلا موافقة لكل جهاز**. تظهر أجهزة المتجر
  لبقية الوكلاء متى كان المتجر معتمداً؛ ويرى المالك أجهزته دائماً.

## 3. القرارات التقنية (أتخذها بقيم افتراضية)

- **تخزين الصور:** Firebase Storage (الحزمة `firebase_storage` موجودة).
  المسار `product_images/{ownerUid}/{productKey}/{imgId}.jpg`. نخزّن في
  قاعدة البيانات **روابط التنزيل** فقط.
- **اختيار الصور:** `image_picker` (متعدّد)، حدّ **5 صور/جهاز**، ضغط
  معقول قبل الرفع. يعمل على الجوال والويب.
- **السعر:** رقم + عملة نصية (افتراضياً «د.ع»).

## 4. نموذج البيانات (Firebase RTDB)

تعديل `stores/{storeKey}`: يصبح `url` **اختيارياً** (يُتحقّق من كونه https
فقط إن وُجد). بقية الحقول كما هي.

عقدة جديدة `products/{productKey}` (معرّف push):

| الحقل | النوع | ملاحظات |
|------|------|---------|
| `storeKey` | String | مفتاح متجر المالك (للربط والعرض داخله) |
| `ownerUid` | String | uid المالك (قفل الكتابة) |
| `ownerName` | String (≤80) | اسم المكتب للعرض |
| `description` | String (1..500) | وصف الجهاز (أساسي) |
| `title` | String? (≤80) | اسم/عنوان الجهاز |
| `price` | number? (≥0) | السعر |
| `currency` | String? (≤8) | العملة (افتراضياً د.ع) |
| `whatsapp` | String? (≤30) | رقم واتساب للطلب |
| `images` | list | روابط https للصور (1..5) تحت `images/0..4` |
| `createdAt`/`updatedAt` | number | ServerValue.timestamp |

**لا اعتمادات.** لا حقل `approved` على الجهاز — يَرِث اعتماد المتجر.

## 5. القواعد

**RTDB `products`** (على نمط `stores`): read = أدمن أو دور agent. write
= أدمن أو (دور agent و`data.ownerUid`/`newData.ownerUid` == auth.uid معاً
لمنع الاختطاف). validate: `description` 1..500، `images` موجودة وغير
فارغة وكل عنصر https ≤500 وعددها ≤5، `title` ≤80، `price` رقم ≥0،
`currency` ≤8، `whatsapp` ≤30، `storeKey`/`ownerUid` نصّان، `$other`→false.
اختبار محاكي `tool/product_rules_test.mjs`.

**Firebase Storage** `storage.rules`: تحت `product_images/{uid}/**` الكتابة
إن `request.auth.uid == uid` ونوع المحتوى صورة وحجم ≤ ~3MB؛ القراءة لأي
مستخدم مسجّل. (يُنشر مع RTDB؛ راجع [[netagent-firebase-rules]].)

## 6. الواجهة

- **المشتريات** (شبكة المتاجر) كما هي. الضغط على متجر → **`StoreDetailScreen`**.
- **`StoreDetailScreen`**: ترويسة (شعار/اسم/مكتب، وزر «زيارة الموقع» إن
  وُجد رابط → iframe/WebView الحالي)، ثم **شبكة أجهزة** (أول صورة + الاسم +
  السعر). الضغط على جهاز → **`ProductDetailScreen`** (معرض صور + وصف + سعر +
  زر واتساب). للمالك/الأدمن: زر **«أضف جهازاً»** وتعديل/حذف أجهزته.
- **`ProductFormScreen`**: اختيار صور (حتى 5)، وصف، اسم، سعر، عملة، واتساب،
  رفع إلى Storage ثم حفظ الروابط.
- **`StoreFormDialog`**: حقل الرابط يصبح «رابط الموقع (اختياري)».

## 7. الخدمة

`lib/services/product_service.dart`: نموذج `Product` + `fromSnapshot` +
`ProductSubmission` + `validateSubmission` (نقيّة)، و I/O: `loadForStore`,
`add/updateOwn/deleteOwn` (ورفع الصور عبر Storage), `deleteAny` (أدمن).

## 8. الاختبارات

- وحدة `test/product_service_test.dart`: تحليل اللقطة (incl. images list)،
  `validateSubmission` (وصف فارغ/طويل، بلا صور، سعر سالب).
- محاكي `tool/product_rules_test.mjs`: المالك يضيف/يعدّل/يحذف جهازه؛ لا
  يكتب جهاز غيره؛ غير الوكلاء لا يقرؤون؛ الأدمن يحذف أياً.
- واجهة `test/product_form_test.dart`: نموذج الجهاز يرفض وصفاً فارغاً/بلا صور.
- (قواعد Storage تُراجَع يدوياً — لا محاكي سهل هنا.)

## 9. النطاق

**MVP:** أجهزة بصور/وصف/اسم/سعر/واتساب داخل المتجر، رفع صور إلى Storage،
حرية الإضافة للوكيل المعتمد. **مؤجّل:** السلة/الدفع، المخزون/الكمية،
التصنيفات، البحث داخل الأجهزة، الإشعار عند توفّر جهاز.

## 10. الأمان والخصوصية

صور ووصف عامّة فقط؛ لا اعتمادات. الكتابة مقفلة على المالك (RTDB + Storage).
واتساب يفتح `wa.me`. iframe الموقع https فقط. حدود الحجم/العدد تمنع الإساءة.
